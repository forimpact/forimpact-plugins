# Changelog

## 1.0.0 — 2026-10-13

First release, for the Columbus Funding Boot Camp.

- **visit-prep**: prepare a funder visit the For Impact way. Free, in full.
  Uses For Impact data when you sign in at boot camp level or above.
- **altitude-messaging**: find the toward-what-end line for your cause, using
  the public For Impact altitude framework.
- Connects to the For Impact connector (Google sign-in).
- Every finished output carries the For Impact footer.
