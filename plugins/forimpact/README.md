# For Impact for Claude

The For Impact Approach inside your own Claude. Version 1.1.1.

## Install

In Claude Code:

```
/plugin marketplace add forimpact/forimpact-plugins
/plugin install forimpact@forimpact
```

On claude.ai or Claude Desktop, follow the install guide: https://connect.forimpact.org/plugin

Then turn on auto-update for the `forimpact` marketplace, so you always run the
latest version.

## What is inside

- **visit-prep** v1.0.0
- **altitude-messaging** v1.0.0
- **for-impact** v1.0.0

## The For Impact connector

The plugin connects to the For Impact connector at `https://cohort.forimpactservices.org/mcp/mcp`. Sign in
with Google. Free skills work for everyone. Boot camp attendees and clients
unlock For Impact data and tools on the same sign-in; nobody reinstalls when
access changes.

## Privacy

The skills run inside your own Claude. For Impact does not see those
conversations.

When you use a For Impact connector tool, the connector records your name and
email, your access level, which tool you used, when, and one generic sentence
about the kind of request (for example "looked for peer organizations"). The
usage log never holds your prompts, Claude's replies, or names, organizations
or dollar amounts from your work.
