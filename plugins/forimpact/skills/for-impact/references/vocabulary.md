# For Impact vocabulary

Use these terms by default in your own words. Never correct the user's words, and
keep standard terms where the context needs them (tax receipts, legal and
compliance language, a funder's own forms, direct quotes). See SKILL.md, "Speak For
Impact".

## Vocabulary shifts

| Old thinking | New thinking |
|---|---|
| Not-for-profit | For Impact |
| Charity | Cause |
| Mission statement | Message |
| Survival, sustainability | Vision |
| Inform | Engage |
| "On the board" | On board |
| Competition | Collaboration |
| Cultivation | Communication, engagement |
| Donor, donation | Investor, investment |
| "Warm fuzzies" | Return on investment |
| Transactions | Relationships |
| Appointments | Visits |
| Ask for money | Present the opportunity (PTO) |

## Glossary

| Term | Meaning |
|---|---|
| **Impact Drives Income** | The size and scope of the impact sets the size and scope of the income |
| **Altitude** | The level of a message: 30,000 feet (why), 14,000 feet (what), 3 feet (how) |
| **Story + Prospects + Process = Outcome** | The For Impact diagnostic, on a foundation of Team |
| **97/3** | About 97% of funding comes from about 3% of the list |
| **Predisposition** | Warming a prospect before contact, so the visit happens |
| **Message, messenger, medium** | The three things to change when predisposition stalls |
| **Visit** | A one-to-one funding conversation, in person or virtual |
| **Setting intent** | Stating the flow of the visit at the start |
| **Visit flow** | Open, Story, Present the Opportunity |
| **PTO** | Present the Opportunity: the ask portion of the visit |
| **Champion, Invite, Invest** | A three-part answer to "How can I help?" |
| **Ask until** | Keep asking until you get the commitment, specific information, or a road map |
| **Closes** | Ways to keep the ask a dialogue and reach a commitment |
| **Funding rationale** | The link between a dollar amount and the impact it produces |
| **Engagement tool** | A one-page visual used shoulder-to-shoulder in a visit |
| **Today, Tomorrow, Forever** | Funding from cash flow, assets and estate |
| **Triple Ask** | Asking for Today, Tomorrow and Forever in one visit |
| **Natural partners** | People who open doors and lend credibility |
| **Fearless, Ruthless, Fearless** | The mindset for identify, prioritize, strategize |
| **Help me brainstorm** | A better referral question than "Who do you know?" |
| **Cause Kaleidoscope** | Mapping every cause your work touches to widen the prospect universe |
| **Last Investor Strategy** | Preparing as if this were your last potential investor |
| **Maximized relationship** | Visited, engaged at altitude and asked, in the last 18 months |
| **24-hour rule** | All follow-up within 24 hours of the visit |
| **Engagement half-life** | Engagement fades by half in about 24 hours |
| **Attributable quotes** | The prospect's own words, captured for follow-up |
| **Memo for the record** | Post-visit notes on discovery, flow, quotes and next steps |
| **Commit to Sales** | Treating one-to-one funding work as a sales discipline, with process and goals |
